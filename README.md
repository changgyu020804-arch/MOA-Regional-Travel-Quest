# 모아로드 서울

서울 25개 구의 동네 퀘스트를 체험하며 탐험 지도를 채우고, 자동차 로봇 **모아**의 의상을 모으는 Pleos Connect 차량용 앱 기획입니다.

## 기획 의도

익숙한 길 주변의 시장, 공원, 문화유산을 동네 퀘스트로 발견합니다. 관심 장소를 즐겨찾기하거나 코스에 담고, 방문 후에는 탐험 기록과 모아의 꾸미기 아이템으로 여행을 남깁니다.

## 체험 흐름

1. **탐험 지도**에서 지역을 골라 활동과 예상 소요 시간을 살펴봅니다.
2. **퀘스트**를 선택하고 가상 이동과 주차 판정을 체험합니다. 이동 중에는 퀘스트 선택과 꾸미기 조작을 제한합니다.
3. 주차 후 안전 확인과 미션 항목을 체크하면 해당 지역의 진행도가 올라갑니다.
4. **모아의 차고**에서 완료한 테마의 의상을 해금해 착용합니다.

## 시연 범위

이전 데모는 Pleos Connect v2.1.0(Android 14, API 34)의 2560 × 1440 px, 160 dpi 환경에서 확인했습니다. 위치·이동·주차 판정은 가상 데이터이며, 주행 제한 상태에서는 조작을 잠그는 방식으로 설계했습니다.
