# 모아 지역 여행 퀘스트

팀 토끼발의 초기 브라우저 데모입니다. 새 동네를 발견하면 지도에 색이 채워지고, 음식·명소·카페 미션을 완료하면 동행 캐릭터 모아의 의상이 열립니다.

## 실행 방법

저장소를 내려받거나 복제한 뒤 [demo/index.html](demo/index.html)을 Chrome 또는 Edge에서 엽니다. 인터넷 연결과 별도 설치 없이 실행할 수 있습니다.

1. **탐험**에서 종로구·성동구·마포구 중 한 곳을 선택합니다.
2. **이 지역으로 가상 이동 → 도착 · 가상 주차**를 누릅니다. 첫 방문 지역이 연한 파랑으로 표시됩니다.
3. 음식·명소·카페 미션을 완료합니다. 1~2개를 완료하면 중간 파랑, 3개를 완료하면 진한 남색으로 바뀝니다.
4. **모아의 차고**에서 해금된 의상을 착용하거나, **발자취**에서 가상 방문·미션 기록을 확인합니다. 화면의 **데모 초기화**로 처음부터 다시 체험할 수 있습니다.

## 개발 범위

- 서울 25개 구 경계를 표시하고, 시범 지역 3개 구에서 총 9개의 예시 퀘스트를 체험할 수 있습니다.
- 가상 이동 중에는 지도·기록·의상 조작이 잠깁니다. 가상 주차 버튼을 누르면 방문이 기록됩니다.
- 방문 횟수, 퀘스트 완료, 의상 착용 상태는 브라우저 저장소에 보관합니다.
- 후속 개발은 Pleos Connect용 Android 앱과 차량 SDK 연동입니다. 실제 위치·주차·체류 기반 방문 판정, 내비게이션 연동, 이동 경로 지도 및 전국 확장은 후속 범위입니다.

## 자료 출처

서울 자치구 경계는 [southkorea/seoul-maps](https://github.com/southkorea/seoul-maps)의 KOSTAT 2013 간소화 GeoJSON을 화면 좌표로 투영했습니다. [지도 라이선스](demo/licenses/MAP-LICENSE.txt)

모아 캐릭터는 프로젝트의 기존 자동차 로봇 SVG를 사용합니다.
