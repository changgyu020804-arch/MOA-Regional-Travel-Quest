# 모아로드 서울

팀 토끼발의 **모아(MOA) 지역 여행 퀘스트** 웹 프로토타입입니다. 서울 25개 구의 퀘스트 150개를 체험하고, 지도에 탐험 진행도를 채우며 캐릭터 모아의 의상·장비·배지 등 58개 항목을 해금할 수 있습니다.

## 실행 방법

1. GitHub에서 **Code → Download ZIP**을 선택해 내려받고 압축을 풉니다.
2. [demo/index.html](demo/index.html)을 Chrome 또는 Edge에서 엽니다.
3. **퀘스트 → 미션 살펴보기 → 이 퀘스트 시작**을 선택합니다.

지도와 캐릭터, 퀘스트 데이터가 HTML에 포함되어 있어 데모는 오프라인에서 실행됩니다. 외부 지도와 공식 안내 링크를 열 때는 인터넷 연결이 필요합니다.

## 데모 시연

1. **가상 이동 시작**을 누릅니다. 이동 중에는 탐험 화면의 조작이 잠깁니다.
2. 도착 후 **가상 합법 주차 지점 확인**을 체크합니다. 거리는 100m 이내, 정확도 오차는 30m 이내, 속도는 0, 기어는 P, 주차브레이크는 작동 상태로 설정합니다.
3. **자동 판정**을 누르면 가상 5분 체류를 약 7초에 시연합니다. 주차나 위치 조건을 벗어나면 체류 시간이 초기화됩니다.
4. 안전 확인과 활동 항목 세 가지를 체크하고 **데모 완료 · 보상 받기**를 누릅니다.
5. **모아의 차고**에서 완료한 테마의 의상을 해금하고 착용합니다. **탐험 기록**에서 완료 이력과 코스를 확인합니다.

## 저장과 구현 범위

데모와 개인 기록은 브라우저에 모드별로 저장됩니다. 탐험 기록 화면에서 JSON 백업을 내려받거나 복원할 수 있습니다. 이 데모는 가상 차량 신호를 사용하며, 실제 차량 SDK·GPS·내비게이션 연동은 후속 개발 범위입니다.

## 소스 수정

화면 구조, 스타일, 퀘스트 데이터, 캐릭터와 동작 코드는 [demo/src/](demo/src/)에 있습니다. 수정한 뒤 저장소 루트에서 Python 3로 다음 명령을 실행하면 독립 실행용 HTML이 다시 생성됩니다.

```sh
python demo/build.py
```
